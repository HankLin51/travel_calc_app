# 🧮 海外旅遊《匯率計算》PWA App

專為海外購物量身打造的 **日式無印質感風即時匯率、購物退稅與信用卡算牌 App**。

## 🌟 核心特色
- 🇯🇵 🇰🇷 🇹🇭 🇻🇳 🇨🇳 🇸🇬 🇲🇾 🇪🇺 🇺🇸 🇬🇧 **多國即時匯率換算**（自動對接 Open Exchange Rates API，支援離線快取）
- ➕ **雙重加法功能**：支援在輸入框輸入 `1500+2300+450` 多樣商品算式，兼有手機實體 `[ ➕ ]` 按鈕與 Quick Add 快捷加數晶片
- 💳 **四大信用卡回饋試算**：台新 Richart (3.3% 台新Point)、富邦 J卡 (3.0% J Points)、國泰 CUBE (3.0% 小樹點)、元大鑽金 (2.2% 現金)
- 🎁 **點數與現金回饋嚴格分離**：點數回饋獨立採發，不加進現金扣款總和
- 🛍️ **各國購物退稅預估**：支援日本 10%、韓國 6%、泰國 5.5%、越南 8.5%、中國 9%、新加坡 7%、歐元區 12% 退稅計算
- 📌 **購物試算歷史紀錄**：逛街購物一鍵儲存筆記
- 📱 **全離線 PWA 支援**：可直接一鍵「新增至手機主畫面」當作原生手機 App 使用！

## 🚀 PWA 免費安裝步驟
1. 使用 iPhone (Safari) 或 Android (Chrome) 打開 GitHub Pages 網址。
2. **iPhone**: 點擊 Safari 下方「分享」按鈕 ➔ 選擇 **「新增至主畫面」**。
3. **Android**: 點擊 Chrome 右上角選單 ➔ 選擇 **「安裝應用程式 / 新增至主畫面」**。
